# Tab Archiver

一个轻量级的 Chrome 浏览器扩展，只需一键即可保存和恢复浏览器标签页。

如果你经常需要同时打开很多浏览器标签页，在关闭 Chrome、重启电脑或切换不同工作任务时，你可能不希望丢失当前的工作环境。

**Tab Archiver** 可以帮助你快速保存当前打开的标签页，并在之后随时恢复。

## ✨ 功能

* 📌 一键保存当前打开的所有标签页
* 🔄 快速恢复之前保存的标签页
* 💾 即使关闭 Chrome 或重启电脑，已保存的标签页仍然可以使用
* 🧹 简单、轻量，不占用过多资源
* 🔒 保存的标签页信息存储在浏览器本地
* 🚀 无需注册账号，也不需要连接外部服务器

## 📸 使用方法

基本使用流程：

1. 打开你工作或学习需要使用的标签页。
2. 点击 **Tab Archiver** 浏览器扩展。
3. 保存当前打开的标签页。
4. 关闭 Chrome 或重启电脑。
5. 再次打开 Chrome。
6. 打开 **Tab Archiver**，恢复之前保存的标签页。

通过这种方式，你可以方便地保存不同工作或学习任务所需要的浏览器工作环境。

## 🧩 安装

目前，Tab Archiver 可以通过 Chrome 的 **开发者模式（Developer Mode）** 和 **加载已解压的扩展程序（Load unpacked）** 功能进行安装。

### 第一步：下载项目

克隆此 GitHub 仓库：

```bash
git clone https://github.com/WeipingWu2023/tab-archiver.git
```

### 第二步：打开 Chrome 扩展程序页面

打开 Chrome，在地址栏输入：

```text
chrome://extensions/
```

然后按 **Enter**。

### 第三步：开启开发者模式

在右上角找到 **开发者模式（Developer mode）**，将其打开。

### 第四步：加载扩展程序

点击左上角的 **加载已解压的扩展程序（Load unpacked）**。

然后选择你刚刚下载的 `tab-archiver` 项目文件夹。

### 第五步：开始使用

安装成功后，Tab Archiver 就会出现在 Chrome 的扩展程序列表中。

你可以点击 Chrome 工具栏中的扩展程序图标，然后将 **Tab Archiver** 固定到工具栏，方便以后快速使用。

## 🔒 隐私

Tab Archiver 不需要注册账号，也不需要将你的数据上传到服务器。

你保存的标签页信息存储在浏览器本地。

## 🚀 项目目标

Tab Archiver 的目标很简单：

> **让你可以随时保存当前的浏览器工作环境，并在需要的时候快速恢复。**

无论是工作、学习，还是处理不同的项目，都可以使用 Tab Archiver 保存你的标签页。
